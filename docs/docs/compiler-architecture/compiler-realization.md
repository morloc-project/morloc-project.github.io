# 14.5. Realization

Morloc Manual > Compiler Architecture | https://morloc-project.github.io/docs/compiler-architecture/compiler-realization.html | prev: https://morloc-project.github.io/docs/compiler-architecture/compiler-effects.md | next: https://morloc-project.github.io/docs/compiler-architecture/compiler-sharing.md

**STUB**: Specifies realization: choosing, for every call in a program, which language implementation to use when several are available. Defines the search space, the cost model (including the cost of crossing between languages), how ties are broken, and the guarantees about the result. Explains how realization decides how the program is split into pools.
