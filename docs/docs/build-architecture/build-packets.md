# 13.4. Packet protocol

Morloc Manual > Build Architecture | https://morloc-project.github.io/docs/build-architecture/build-packets.html | prev: https://morloc-project.github.io/docs/build-architecture/build-lifecycle.md | next: https://morloc-project.github.io/docs/build-architecture/build-shm.md

**STUB**: Specifies the packet protocol that the nexus and pools speak: the fixed header, every packet type, metadata blocks, and how a payload is carried either inline or by reference to shared memory. Defines error packets, the transport between processes, and the framing and ordering rules a conforming implementation must follow.
