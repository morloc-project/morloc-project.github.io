# 13.12. Run directory, caching and logging

**STUB**: Specifies the state a run keeps outside the process. Defines the run directory layout and its activation rules, how cache keys are computed and when a cached result is reused or invalidated, and the format and levels of the run log. States the concurrency guarantees when several runs share a cache or a run directory.
