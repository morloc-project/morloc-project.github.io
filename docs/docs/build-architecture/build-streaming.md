# 13.10. Streaming and memory mapping

Morloc Manual > Build Architecture | https://morloc-project.github.io/docs/build-architecture/build-streaming.html | prev: https://morloc-project.github.io/docs/build-architecture/build-errors.md | next: https://morloc-project.github.io/docs/build-architecture/build-collect.md

**STUB**: Specifies streams: values too large or too long-lived to hold in memory at once. Defines the stream file format, how it is divided into chunks, and how the chunks are compressed, including write-behind compression. Covers how readers map a stream into memory and access it at random, which element types and variants a stream may hold, and the guarantees for a stream that is still being written.
