# 13.11. Collect, fold, parse and render

Morloc Manual > Build Architecture | https://morloc-project.github.io/docs/build-architecture/build-collect.html | prev: https://morloc-project.github.io/docs/build-architecture/build-streaming.md | next: https://morloc-project.github.io/docs/build-architecture/build-runs.md

**STUB**: Specifies the CLI’s data-flow directives: `@collect` and `@fold`, which gather a stream into a value, and `@parse` and `@render`, which convert between external formats and typed values. Defines buffering and when data is materialized versus streamed. Covers how parsers and formatters are chosen, how several renders write to separate named outputs, and the full path data takes from input file to output.
