# 12. Installation, Versions, and Deployment

Morloc Manual | https://morloc-project.github.io/docs/install/ | prev: https://morloc-project.github.io/docs/languages/futhark.md | next: https://morloc-project.github.io/docs/install/container-engine.md

`mim` is distributed as a static binary for x86 Linux, Linux ARM, and Apple Silicon macOS. The installer in [Installing `mim`](https://morloc-project.github.io/docs/getting-started/installing.md#installing-mim) fetches it; the binaries themselves are on the [morloc-manager releases page](https://github.com/morloc-project/morloc-manager/releases). Each Morloc release is a version `mim` can provision into an environment, and this chapter covers the commands that create, pin, customize, and deploy those environments. The full `mim` reference is [`mim` (Morloc Installation Manager)](https://morloc-project.github.io/docs/utilities/mim.md).
